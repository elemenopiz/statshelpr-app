step 1 of 5

Welcome to statshelpr.

A tiny tutor that lives inside Canvas. Click one button per question and we'll work out the answer — concept questions or R-code calculations alike — and select it for you.

Built on the same R toolkit your course uses: tidyverse, mosaic, moderndive, infer.

step 2 of 5

Set your API URL.

Click the statshelpr icon in your Chrome toolbar (you may need to pin it from the puzzle-piece menu). Paste the production API URL:

https://statshelpr-co4kzmola-elemenopizs-projects.vercel.app

Leave the license key blank for now — the dev API runs ungated.

step 3 of 5

Open a Canvas quiz.

On UT Canvas, navigate to any quiz page. Wait for the questions to load — you should see a small solve button appear next to each question heading.

Question 1 solve
Which measure of center is most robust to outliers?
A. mean
✓ B. median
C. mode
D. range

Click solve → spinner → the correct choice is selected automatically.

step 4 of 5

For questions that need data files.

Some questions reference a CSV (e.g., "Using the houses dataset, compute…"). Drop your data files into the small panel in the bottom-right of the Canvas page — once per course, not once per question.

Files persist for 7 days in your browser. They never leave your machine except attached to a single solve request.

step 5 of 5

You're set.

A quick reference for as you go:

  • solve the button next to each question — click to auto-answer
  • spinner — Kimi is thinking (concept ≈ 2-3 sec, calc ≈ 6-12 sec)
  • ✓ green — answered (the correct choice is selected for you)
  • ! red — something failed (hover for the message)

Re-open this guide anytime from the extension popup.
