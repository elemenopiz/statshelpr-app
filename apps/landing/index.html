Question 3

A sample of n = 24 students took a memory test before and after a study-skills workshop. The mean score difference was 4.2 (SD = 8.1). At α = 0.05, what should the researcher conclude?

A. Fail to reject H₀ — no evidence of improvement
B. Reject H₀ — scores improved significantly
C. Reject H₀ because SD exceeds the mean difference
D. The test is invalid without the population σ
reading question… Worked solution

Paired design → run a one-sample t-test on the differences.

H₀: μd = 0  ·  H₁: μd ≠ 0  ·  df = 23

t <- 4.2 / (8.1 / sqrt(24))
2 * pt(t, df = 23, lower.tail = FALSE)
#> t = 2.54   p = 0.0182

p = 0.018 < 0.05 → reject H₀.

Answer B Scores improved significantly.
